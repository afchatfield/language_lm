langlm

Grammar correction for learners of German and Spanish. The model runs in this tab; nothing you type leaves your machine.

Checking for a cached model…
⌘/Ctrl + Enter

A fine-tuned, vocab-trimmed EuroLLM-1.7B at 4-bit, run by wllama (llama.cpp compiled to WebAssembly). The first visit downloads the model once; after that it loads from your browser's storage and works offline.

Explanations are rendered from the error type the model reports. The command-line tool re-derives the type with ERRANT, which is more often right; that needs spaCy, which does not run here.
